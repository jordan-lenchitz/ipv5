# ipv5 utility

## features
- **ipv5 dashboard**: view your current quantum-entangled dynamic ip
- **mac entanglement**: xor your mac address with ipv5 for "modern" security
- **port predictor**: uses your device's battery percentage to suggest the best open port for whatever
- **boomerang ping**: routes your localhost ping through the moon for maximum accuracy
- **slow-dns resolver**: a dns resolver that takes its time, just like the old days
- **ipv7 mode**: unleash the future of networking with base64 addresses and chaotic ui

## the ipv1-9 protocol specification
we at ipv5 are proud to support the full evolution of networking protocols:

| protocol | name | format | use case |
| :--- | :--- | :--- | :--- |
| **ipv1** | unary smoke signals | `1111.11.1111` | hand-cranked modems and smoke signals |
| **ipv2** | pure binary | `01101.011` | sentient toasters and coin-flip logic |
| **ipv3** | geographical | `123-main-st.apt-4` | physical mail routing (usps fallback) |
| **ipv4** | boring | `192.168.1.1` | normies and legacy hardware |
| **ipv5** | quantum xor | `x.x.x.x.x [flux]` | our current flagship protocol |
| **ipv6** | try-hard | `2001:db8::1` | people who think hex is cool (often realn't) |
| **ipv7** | base64 premium | `atdwb2lksjk=` | 9-octet chaos for premium users |
| **ipv8** | emoji routing | 🍎.🚀.👽.🍕 | gen z networking stacks |
| **ipv9** | sub-ether | `yesterday.3pm` | packets arrive before they are sent |
